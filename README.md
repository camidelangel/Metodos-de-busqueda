# Unidad 6: Métodos de Búsqueda

## Descripción del proyecto

Este proyecto contiene dos prácticas realizadas en Java correspondientes a la Unidad 6: Métodos de Búsqueda.

El objetivo es implementar y probar dos métodos de búsqueda:

- **Búsqueda secuencial:** recorre los elementos de un arreglo hasta encontrar el valor buscado o terminar de revisar todos los elementos.
- **Búsqueda binaria:** busca un elemento dividiendo el intervalo de búsqueda a la mitad. Para funcionar correctamente, el arreglo debe estar ordenado de menor a mayor.

## Archivos del proyecto

- `PracticaBusquedaSecuencial.java`: contiene el método de búsqueda secuencial y sus casos de prueba.
- `PracticaBusquedaBinaria.java`: contiene el método de búsqueda binaria y sus casos de prueba.

## Requisitos

- Tener instalado Java JDK.
- Contar con una terminal o consola de comandos.
- Tener los archivos del proyecto en una misma carpeta.

## Instrucciones para ejecutar el programa

### 1. Descargar el proyecto

Descargar o clonar el repositorio de GitHub y abrir la carpeta donde se encuentran los archivos Java.

### 2. Abrir la terminal

Abrir una terminal o consola de comandos dentro de la carpeta del proyecto.

### 3. Compilar la búsqueda secuencial

Ejecutar el siguiente comando:

```bash
javac PracticaBusquedaSecuencial.java
```

### 4. Ejecutar la búsqueda secuencial

```bash
java PracticaBusquedaSecuencial
```

Resultado esperado:

```text
Posicion de 88: 3
Posicion de 100: -1
```

### 5. Compilar la búsqueda binaria

Ejecutar:

```bash
javac PracticaBusquedaBinaria.java
```

### 6. Ejecutar la búsqueda binaria

```bash
java PracticaBusquedaBinaria
```

Resultado esperado:

```text
Indice de 173: 5
Indice de 130: -1
```

Con estas prácticas se implementaron dos métodos de búsqueda en Java. La búsqueda secuencial permite encontrar elementos sin necesidad de ordenar el arreglo,
mientras que la búsqueda binaria permite realizar búsquedas más rápidas cuando los datos están ordenados.

Ambos métodos regresan la posición del elemento cuando se encuentra y `-1` cuando no existe dentro del arreglo.
